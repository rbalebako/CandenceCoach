# Cadence Coach

Cadence Coach is a Garmin Connect IQ running app for the fēnix 7S. It guides runners through an eight-session, four-week plan for gradually increasing cadence and practicing running-form drills. Sessions run on the watch and record as running activities.

This is designed for slow runners, like me, who want to improve form and technique when running.  The one month recommendations for improving running were generated by Gemini and are shown in specs.MD.  No human with any health knowledge was used; your results may vary.


## What it does

- Guides each session through timed intervals, recovery periods, and steps that you advance with the LAP button.
- Shows live cadence and the current target during cadence intervals.
- Provides an audible and/or vibration metronome during target segments.
- Measures a cadence baseline during the first session and uses it to set later targets. You can also configure a baseline manually.
- Displays a post-run summary with elapsed time, average cadence, time on target, and baseline information.
- Adds brief form-drill instructions after sessions in weeks 1–3.

## The four-week plan

| Session | Workout |
|---|---|
| Week 1 · Run 1 | Easy running with a 60-second baseline measurement |
| Week 1 · Run 2 | Warm-up, then 4 × 30 seconds at 170 steps per minute with 90-second recoveries |
| Week 2 · Run 1 | 4 × 1 minute at baseline + 6, with 2-minute recoveries; easy running to 25 minutes |
| Week 2 · Run 2 | Six 30-second pickups at baseline + 6, started at landmarks; easy running to 30 minutes |
| Week 3 · Run 1 | 3 × 2 minutes at baseline + 8, with 2-minute recoveries, followed by a cool-down |
| Week 3 · Run 2 | Four 15-second hill strides, followed by a cool-down |
| Week 4 · Run 1 | Two 5-minute segments at 172, with 3 minutes of easy recovery |
| Week 4 · Run 2 | 30 minutes of easy running, focusing on light, quick steps |

The week 1 baseline is measured in the first run and saved when that activity is saved. Until a baseline is available, relative targets use 160 steps per minute. The hill-stride session includes a 10-minute easy warm-up. Weeks 1–3 finish with the form drill assigned to that week; drills can be skipped by saving the activity.

## Using the watch app

1. Select a session. Its goal screen is followed by a ready screen.
2. Press **START** to continue from the goal screen, then press **START** again to begin recording.
3. During a run, **START** pauses and opens the Resume, Save, and Discard menu. **BACK/LAP** advances a manual step or skips the current step.
4. To save early, choose **Save** from the pause menu, review the summary, then press **START** to save and exit.

Touchscreen taps and swipes are ignored during workouts. Timed steps advance automatically. For landmark and hill steps, press LAP when you reach the indicated point.

Cadence is shown in steps per minute (spm). During target segments, green indicates within 3 spm of the target; orange and red indicate below target (red is more than 8 spm below); blue indicates above target.

## Settings

Open **Cadence Coach → Settings** in the Garmin Connect IQ phone app:

- **Baseline cadence**: Set a value from 1–220 spm, or leave at 0 to use the measured baseline.
- **Metronome**: Choose tone, vibration, both, or off.
- **Beat on**: Choose every step or every other step.

Watch tones must be enabled in the watch's sound settings for audible metronome feedback.

## Build and install

This project is written in Monkey C and targets the **fēnix 7S** (`fenix7s`).

1. Install [Visual Studio Code](https://code.visualstudio.com/), Garmin's Monkey C extension, and the [Connect IQ SDK Manager](https://developer.garmin.com/connect-iq/sdk/).
2. Use the SDK Manager to install a Connect IQ SDK and the fēnix 7S device.
3. Open this project in VS Code. Run **Monkey C: Verify Installation** from the Command Palette and generate a developer key when prompted.
4. Run **Monkey C: Run** and select `fenix7s` to try the app in the simulator. The simulator's Activity Data controls can provide cadence input.
5. To build for the watch, run **Monkey C: Build for Device** and select `fenix7s`. Copy the generated `CadenceCoach.prg` to the watch's `GARMIN/APPS/` folder over USB.

## Project structure

- `source/Plan.mc` defines the session catalogue, workout steps, goals, and drills.
- `source/WorkoutEngine.mc` runs the session, records the activity, tracks cadence, and handles the metronome and baseline.
- `source/WorkoutView.mc` draws the goal, workout, and summary screens.
- `source/Delegates.mc` handles watch-button input and pause/save/discard menus.
